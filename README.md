# 7z Password Manager 🗝️

一个基于 Web 的桌面工具，用于管理压缩文件密码并自动解压加密归档。

**核心流程**：拖拽加密文件到程序 → 自动测试密码库中的所有密码 → 找到匹配密码 → 自动解压到指定目录。未匹配时弹出密码输入窗口，支持临时密码快速选择和自动升级。

---

## 功能一览

### 🔑 密码库管理
- 添加、编辑、删除密码，支持标签和分类
- 自动记录使用次数和最后使用时间
- 批量导入/导出密码（JSON 格式）
- 密码使用 **PBKDF2 + Fernet 加密** 存储

### 🎯 自动密码测试
- 拖拽或通过文件关联打开压缩文件后，自动遍历密码库逐个测试
- 实时显示测试进度（百分比 + 当前测试的密码）
- 找到匹配密码后自动解压到指定目录
- 解压时自动创建 **压缩包同名子文件夹**，避免文件散落

### ✏️ 手动密码输入 + 临时密码下拉菜单
- 密码库中无匹配密码时，弹出窗口手动输入
- **下拉菜单快速选择**：之前保存的临时密码会以下拉列表形式展示，点击即可自动填入密码框
- 支持保存到临时密码库、选择是否解压

### 🕐 临时密码自动升级
- 手动输入的密码可保存为临时密码
- 每次成功使用后记录使用次数
- **可配置自动升级阈值**：使用次数达到设定值后自动加入密码库
  - 设置 `0` = 永不自动升级
  - 设置 `3` = 使用 3 次后自动加入密码库（标签为"自动-文件名"，分类为"自动升级"）
- 已升级的临时密码不再出现在下拉菜单中

### 📂 多文件队列处理
- 支持同时拖入或传递多个文件，自动排队依次处理
- 桌面图标拖拽（文件关联）时同样支持多文件排队

### 📋 实时运行日志
- 首页始终显示实时日志面板，随时了解任务进度
- 日志按类型着色（信息/成功/错误/警告）

### 🔄 心跳保活与自动关闭
- 浏览器标签页打开时，每 10 秒发送心跳
- 关闭标签页后 10 秒内自动关闭后台服务进程，不留驻留

### ⚙️ 灵活配置
- 7z 路径自动检测或手动指定
- 自定义解压输出目录
- 自动解压开关
- 解压完成后自动关闭开关
- 临时密码自动升级阈值设置

## 快速开始

### 系统要求

- **Windows 10/11**（推荐，文件关联功能仅 Windows）
- macOS / Linux（理论支持，Web 界面可运行）
- Python 3.8+
- 需要安装 **[7-Zip](https://www.7-zip.org/)**（或兼容的 7z 命令行工具）

### 方式一：直接运行（Python）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行程序
python main.py

# 3. 拖入加密文件（可选）
python main.py encrypted.7z
```

启动后浏览器自动打开 `http://127.0.0.1:8765`。

### 方式二：打包为独立 EXE（推荐 Windows 用户）

```bash
# 自动安装 PyInstaller 并打包
python build_exe.py
```

生成的可执行文件在 `dist/7zPasswordManager.exe`。

**注册文件关联**（需要管理员权限，双击 .7z/.zip/.rar 自动用本程序打开）：

```bash
dist\7zPasswordManager.exe --register
```

**卸载文件关联**：

```bash
dist\7zPasswordManager.exe --unregister
```

### 方式三：Windows 一键设置

双击 `setup_windows.bat`，选择：
1. **直接运行** — 需要已安装 Python 环境
2. **打包为 EXE** — 自动安装 PyInstaller 并生成独立可执行文件
3. **注册文件关联** — 将 .7z/.zip/.rar 文件关联到本程序

## 使用指南

### 1. 密码库管理

切换到「密码库」标签页：
- **添加密码**：点击「添加密码」，填写标签、密码、分类
- **编辑/删除**：表格行末的 ✏️ / 🗑️ 按钮
- **批量删除**：勾选后点击「删除」
- **导入/导出**：顶部工具栏的 📤/📥 按钮，JSON 格式

### 2. 处理加密文件

**拖拽文件**：将压缩文件拖入窗口的虚线区域，或点击「打开文件」选择

处理流程：
```
拖入文件 → 检测是否加密
  ├─ 未加密 → 直接解压到输出目录
  └─ 已加密 → 遍历密码库测试
       ├─ 找到匹配 → 自动解压 ✅
       └─ 未匹配 → 弹出手动密码窗口
            ├─ 下拉菜单选择临时密码
            └─ 手动输入新密码 → 测试
                 ├─ 正确 → 保存到临时密码 + 解压
                 └─ 错误 → 重试
```

### 3. 临时密码与自动升级

切换到「临时密码」标签页：
- 手动输入的正确密码会自动保存到这里
- **手动加入密码库**：选中后点击「📥 加入密码库」
- **自动升级**：在「设置」中启用，设定阈值（如 3）
  - 临时密码使用达到 3 次后自动加入密码库
  - 已升级的密码不再出现在手动弹窗的下拉菜单中

### 4. 设置

| 设置项 | 说明 |
|--------|------|
| 7z 路径 | 自动检测或手动指定 7z 命令行路径 |
| 解压输出目录 | 默认 `~/7zExtracted`，解压时自动创建子文件夹 |
| 自动解压 | 找到密码后自动解压 |
| 解压后关闭 | 解压完成后自动关闭浏览器标签页 |
| 临时密码自动升级 | 启用后达阈值自动加入密码库 |
| 升级阈值 | 使用次数阈值（0 = 永不自动升级） |

## 数据存储

| 文件 | 路径 | 说明 |
|------|------|------|
| 密码库 | `%APPDATA%/7zPasswordManager/passwords.db` | SQLite，密码加密存储 |
| 配置 | `%APPDATA%/7zPasswordManager/config.json` | 应用设置 |
| 上传文件 | `%APPDATA%/7zPasswordManager/uploads/` | 临时存放待处理的压缩文件 |

- 密码使用 **PBKDF2（600,000 次迭代）+ SHA256 + Fernet** 加密
- 未设置主密码时使用机器相关密钥
- 所有密码仅在内存中解密

## 安全说明

- 密码库使用 PBKDF2（600,000 次迭代）+ SHA256 派生密钥，Fernet 对称加密
- 未设置主密码时，使用机器 ID + 应用路径的哈希作为默认密钥
- 可通过设置主密码增强安全性（加密密钥由主密码派生）
- 临时密码同样加密存储
- 关闭浏览器标签页时自动清理 `uploads/` 目录（心跳检测到标签页关闭后触发清理）
